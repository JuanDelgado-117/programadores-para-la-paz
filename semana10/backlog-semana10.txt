Prioridad 1:
Como ciudadano quiero registrar un reporte de un problema en mi comunidad para que pueda ser atendido rápidamente.

Prioridad 2:
Como coordinador quiero recibir una notificación en Telegram cuando se registre un nuevo reporte para hacer seguimiento.

Prioridad 3:
Como miembro del equipo quiero consultar los reportes registrados para conocer el estado de cada caso.

Prioridad 4:
Como administrador quiero actualizar el estado de un reporte para mantener informada a la comunidad.

Prioridad 5:
Como ciudadano quiero recibir una notificación cuando mi reporte haya sido revisado.
