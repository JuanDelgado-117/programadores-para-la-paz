El comando `uname -a` muestra información del sistema operativo, como el kernel de Linux, la 
arquitectura del equipo y otros datos técnicos del sistema.

El comando `whoami` muestra el nombre del usuario que actualmente está utilizando la sesión 
del sistema.

Conocer esta información es útil cuando se administra un servidor porque permite identificar 
el entorno de trabajo, verificar el sistema operativo utilizado y saber con qué usuario se 
están ejecutando las tareas administrativas.
